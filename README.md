# CommerceKit CLI

Official binary distribution repository for CommerceKit CLI.

CommerceKit CLI provides SAP Commerce developer tools for terminals,
scripts, and CI pipelines.

## Releases

Download the explicitly named platform archive from the Releases page:

- macOS ARM64
- macOS x64
- Linux ARM64
- Linux x64
- Windows ARM64
- Windows x64

Verify downloaded assets using the published `SHA256SUMS` file.

## Source code

The CommerceKit source repository is maintained privately. This public
repository contains release metadata and binary distribution assets only.

## Release status

Initial CommerceKit CLI releases are developer previews. macOS and Windows
binaries may be unsigned until platform signing is introduced.

## Documentation

CommerceKit documentation is available at commercekit.tools.
