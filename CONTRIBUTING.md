# Contributing

This repository is the public binary-distribution surface for CommerceKit CLI.
It does not contain the CLI source implementation, and release binaries,
manifests, checksums, tags, and release notes are generated by the private
CommerceKit release pipeline.

Do not submit pull requests that add or replace release binaries or alter a
published release. Published versions are immutable.

Use <https://commercekit.tools/contact> for non-sensitive product feedback and
support. Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

Source-code collaboration begins only after the CommerceKit owner coordinates
the scope and grants access to the private source repository. Invited
contributors follow the workflow documented there.
